NEMO Mystery Days v0.52

【今回の大きな変更】
・事件を順番に解放するストーリー進行方式へ変更
  CASE 01クリア → CASE 02解放 → CASE 03解放 → CASE 04解放
・クリア状況はブラウザの localStorage に保存
・解決済み事件はいつでも再捜査可能
・CASE CLEAR時に次の事件解放メッセージを表示
・CASE 04「はじめての依頼 ― 消えた小さな手紙 ―」を追加
・CASE 04はORIGIN EPISODE。相棒ねも選択をスキップし、最初は一人で捜査
・CASE 04の途中でねもと初めて出会う演出を追加
・CASE 04は犯人探しではなく、手紙が消えた場所・理由・現在地を推理
・CASE 04クリア時に、ねもが助手になる始まりのエピローグを表示

※進行状況は同じ端末・同じブラウザ内に保存されます。ブラウザのサイトデータを削除すると進行もリセットされます。
