ねも探偵局 v0.5

【今回のテーマ】
Nemo NFTを探偵として扱う土台を作る。

【v0.5の変更】
・Nemo番号から能力値を固定生成
・同じNemo番号は毎回同じ能力値
・NFT画像スロットを追加
・assets/nemos/66.png のように画像を置くだけで表示
・画像が無い場合は絵文字へ自動フォールバック
・NFTごとに「観察型 / 推理型 / 会話型 / 直感型」を自動決定

【画像の入れ方】
assets/nemos/ フォルダに、番号をファイル名にしたPNGを置く。
例：assets/nemos/66.png
