ねも探偵局 v0.13

【今回のテーマ】
PC版を「毎回スクロールするUI」から「画面内で完結する捜査机UI」へ変更。

【PC版の変更】
・ページ全体の縦スクロールを基本的に停止
・左の捜査 / 証言パネルと右の事件ファイルを、それぞれ内部スクロール
・現場画像の高さを縮小
・証言カード、人物カード、ボタン、余白をコンパクト化
・「詳しく聞く」の結果欄を固定高さにし、ねもの反応がすぐ見える
・証言を切り替えても画面位置が大きく動かない
・低いノートPC画面ではさらに自動圧縮
・フッターはPCでは非表示

【スマホ】
v0.12までのスマホUIは維持。

【狙い】
PCでは、
証言 → 詳しく聞く → ねもの反応 → 証拠確認
をほぼ同じ画面の中で繰り返せるようにする。
