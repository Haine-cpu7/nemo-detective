ねも探偵局 v0.12

【今回の修正】
ねものキャラクター性と「詳しく聞く」の反応を再設計。

1. ねもの口調
・能力差は残す
・強い言い切り、偉そうなセリフ、普通のゲームNPCっぽいセリフを減らす
・静か / 短い / 少し曖昧 / ねもらしいズレ方に統一

2. 「詳しく聞く」
・毎回ねもが同じ一言をしゃべる仕様を廃止
・その証言に意味のある反応がある時だけ、ねもがしゃべる
・何もなければ証言の追加情報だけ表示
・個体ごと、証言ごとに反応内容を分ける

3. 奇行
・騒がしいギャグではなく、静かな寄り道に変更
・例：花を見る、写真の花瓶を気にする、別のものを眺める
・事件からズレているが、ねもの世界観は壊さない

4. 反応UI
・ねもの反応を少し小さく、補助情報として表示
・証言そのものが主役になるよう調整

【方針】
ねもは「毎回しゃべるナビゲーター」ではない。
必要な時だけ、ぽつりと気づきを置いていく相棒。
