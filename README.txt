ねも探偵局 v0.20

【ねもちゃんのキャラクターを再設計】
過去の「ねもちゃんの日記」とNemo Gardenの雰囲気に合わせて、
探偵NPCのような固い口調をやめました。

基本のねも：
・普通の子として事件を見る
・「あれ？」「うーん」「なんか気になる」から入る
・短く、素朴
・名探偵っぽく断定しない
・気づく時も、本人は大げさに振る舞わない
・個体差は別人格ではなく「どこに目が向くか」で出す

【能力値のつながりを修正】
v0.19までの「観察ボーナス / 推理ボーナス」は、
その場に追加文章を表示するだけで、後のゲームには保存されていませんでした。

v0.20から：
1. 高能力で見つけた情報を「ねもの気づき」として保存
2. 事件ファイルの証拠カードにも残る
3. 後の証言パートで、その気づきを使った専用反応が出る
4. 正しい矛盾を発見した時に「さっきの気づきがここでつながった」反応が出る

例：
観察99で額縁を調査
→「額縁の右端に新しい指の跡」を発見
→事件ファイルへ保存
→「触っていない」という証言で、その観察結果を使って反応

【能力差】
能力差で事件が詰むことはありません。
高能力は「追加情報を見つける / あとでつながる」体験を増やします。
