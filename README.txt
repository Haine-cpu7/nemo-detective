ねも探偵局 v0.16

【スマホ画面遷移の修正】
iPhone Safariで、
下までスクロールした状態から次の画面へ進むと
前画面のスクロール位置が残り、黒い空白から始まることがある問題を修正。

・事件選択 → 探偵選択
・探偵選択 → 事件概要
・事件概要 → 現場捜査
・現場捜査 → 証言
・証言 → 最終推理
・最終推理 → 事件解決

それぞれの画面切替時に、新しい画面の先頭へ自動で戻る。

【Nemoセリフ修正】
戻るボタンや現場確認機能がないのに、
「現場に戻りたい」「現場でもう一度見たい」と言うセリフを削除。

#66の該当反応：
旧「……トイレの場所、現場でもう一度見たい。」
新「……『すぐ戻った』ってところ、少しだけ覚えておきたい。」

画面上で実際にできる操作と、Nemoの発言を一致させる。
